# Exploratory Data Analysis Project

## Objective
Analyze a student dataset to identify patterns, trends, correlations, and influencing factors.

## Dataset
120 student records with study hours, attendance, previous score, assignments, sleep hours, and subject scores.

## Key Findings
- Average Study Hours: 4.52
- Average Attendance: 75.59%
- Average Math Score: 70.01
- Average Science Score: 66.80
- Average English Score: 72.89
- Duplicate rows intentionally included: 2
- Missing values intentionally included for EDA practice.

## Visualizations
Distribution charts, scatter plots, gender distribution, average subject scores, and a correlation heatmap are in `outputs/`.
